# Voyage Web

Site estático em HTML, CSS e JavaScript. As páginas públicas consultam a API local compartilhada em `http://<host-da-página>:3333/api`.

Inicie o banco e a API seguindo o `README.md` da raiz do repositório e abra `index.html` com o Live Server. O navegador nunca acessa o PostgreSQL diretamente.

O conteúdo de notícias, parceiros e regiões começa vazio. O painel administrativo está temporariamente desativado.
